# 🤖 AI Support Ticket Analyzer

**An AI-powered IT support assistant** that analyzes technical issues, identifies potential causes, and suggests troubleshooting steps.

---

## 🛠️ Tech Stack

| Frontend | HTML, CSS, JavaScript, Vite |
| Backend *(planned)* | Python, FastAPI, Pydantic |
| AI *(planned)* | Google Gemini API |
| Testing *(planned)* | pytest |

---

## ✨ Current Features

- Responsive user interface
- Input validation and character counter
- Structured diagnosis interface
- Loading states and error handling

---

## 🧠 Planned AI Analysis

- Ticket category and priority classification
- Problem summary
- Possible causes
- Troubleshooting recommendations
- Escalation recommendation

## 🚀 Getting Started

```bash
git clone https://github.com/chaberskid/ai-support-ticket-analyzer.git
cd ai-support-ticket-analyzer
npm install
npm run dev
```

Open the local URL displayed in your terminal.
